forced-colors strips your palette. Your site should not break.

Windows High Contrast does not ask your site to look nicer. It hands the browser a fixed palette from the operating system and overrides nearly every color you wrote. Your purple button becomes plain text on a flat background. Your link loses its color and looks like a sentence. The green dot that meant online means nothing. The forced-colors media query tells you the mode is active, and the system colors tell you what to draw with.

The fix, in one rule

Borders survive when backgrounds do not. Underlines survive when link color does not. Words survive when a colored dot does not. The system colors are the palette the user chose: Canvas, CanvasText, LinkText, ButtonText, ButtonFace, Highlight.

@media (forced-colors: active) {
  .btn {
    border: 2px solid ButtonText;
    background: ButtonFace;
    color: ButtonText;
  }
  a { color: LinkText; }
}

forced-colors is Baseline, widely available since March 2025. Safari 16 covers macOS and iOS. One honest catch: iOS has no forced-colors mode to turn on, so the readout on an iPhone will say false. That is expected. The simulator above is how you preview it there. On Windows, Chrome and Edge DevTools can also emulate it from the Rendering tab.

The escape hatch, and why to reach for it slowly

forced-color-adjust: none opts an element out of forced colors entirely, so it renders with its own colors exactly as written. It has its uses, a brand logo or a photo that would be unreadable any other way. But the user chose this palette for a reason, so treat it as a scalpel, not a default. And one more honest catch: forced-color-adjust works in Chrome, Edge, and Firefox, but Safari does not support it yet. Do not build on it as a universal escape hatch.

.logo {
  forced-color-adjust: none;
}
Worth knowing: forced-colors is not the same as prefers-contrast. The contrast query reports a preference for more or less contrast and touches none of your styles. Forced colors is not a hint. When it is active, the browser overrides nearly every color property you wrote.
Worth knowing: never rely on color alone for meaning. A green dot, a red border, a greyed-out button. If the meaning lives only in a color, forced colors mode deletes it. Pair it with text, a shape, or an underline.
