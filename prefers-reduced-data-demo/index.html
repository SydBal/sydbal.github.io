3.What else to gate when data is precious

  • Hero and inline images — serve a lite variant or a smaller responsive size (this demo).
  • Autoplay video — show the poster frame; play only on tap.
  • Web fonts — fall back to the system stack instead of downloading hundreds of KB.
  • Heavy animation libraries — skip them and keep the page static.
  • Prefetch / preload of below-the-fold resources — drop it.
  • Server-side: check the Save-Data request header for the same signal.

4.The pattern

// respect the user's data-saver preference
const reduceData = window.matchMedia('(prefers-reduced-data: reduce)');

function chooseHero() {
  // only the chosen file is ever requested
  heroImg.src = reduceData.matches ? 'hero-lite.jpg' : 'hero-heavy.jpg';
}

reduceData.addEventListener('change', chooseHero);
chooseHero();
/* the CSS-only version: hide the heavy stuff */
@media (prefers-reduced-data: reduce) {
  .hero-video { display: none; } /* poster image shows instead */
}
