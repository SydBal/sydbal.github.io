The View Transitions API turns a hard DOM swap into an animated transition with one function call: document.startViewTransition(() => { /* your DOM update */ }). The browser snapshots the before and after states and tweens between them. Click a card in each panel below and compare the plain swap against the transitioned one.

Same-document transitions are Baseline: Chrome/Edge 111+, Safari 18+, Firefox 138+. Cross-document transitions (@view-transition { navigation: auto; }) are newer: Chromium 126+, Safari 18.2+, Firefox still trailing. This demo uses the same-document API, and it skips transitions entirely when you prefer reduced motion.

The code

1. The whole basic API

document.startViewTransition(() => {
  // any DOM update: swap views, re-render a list, toggle a class
  showDetail(item);
});

2. Shared-element morph (thumbnail becomes the hero)

// give both ends the SAME name; it must be unique per snapshot
thumb.style.viewTransitionName = 'hero';
hero.style.viewTransitionName = 'hero';

const t = document.startViewTransition(() => showDetail(item));
t.finished.finally(() => {
  thumb.style.viewTransitionName = '';
  hero.style.viewTransitionName = '';
});

3. Custom animation, pure CSS

::view-transition-old(root) {
  animation: slide-out 320ms ease-in both;
}
::view-transition-new(root) {
  animation: slide-in 320ms ease-out both;
}
@keyframes slide-out { to { transform: translateX(-48px); opacity: 0; } }
@keyframes slide-in { from { transform: translateX(48px); opacity: 0; } }

4. Feature-detect and respect reduced motion

const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;

function update(fn) {
  if (document.startViewTransition && !reduce) {
    document.startViewTransition(fn);
  } else {
    fn(); // plain instant swap: the free fallback
  }
}

Honest notes

  • The fallback is doing nothing. A browser without the API runs your update function directly and the user sees an instant cut. No polyfill needed; you are adding polish, not a dependency.
  • Names must be unique. Two visible elements sharing one view-transition-name in the same snapshot abort the transition. Generate names per item if several could be on screen.
  • Same-document vs cross-document. This page demos same-document transitions. For classic multi-page sites, @view-transition { navigation: auto; } gives you crossfades between full page loads with zero JavaScript, where supported.
  • Reduced motion. View transitions are motion. If the user asked for less of it, skip the transition. This demo checks prefers-reduced-motion live and swaps instantly when it is set to reduce.
