View Transitions Playground

dominic.balass.one

The View Transitions API turns a hard DOM swap into an animated transition with one function call: document.startViewTransition(() => { /* your DOM update */ }). The browser snapshots the before and after states and tweens between them. Below is a tiny travel journal. Click a destination: the photo and the title morph into the detail view. Flip the transitions toggle to feel what the API adds, or try the slide and zoom presets.

Support check (live)

Same-document transitions are Baseline: Chrome/Edge 111+, Safari 18+, Firefox 138+. Cross-document transitions (@view-transition { navigation: auto; }) are newer: Chromium 126+, Safari 18.2+, Firefox still trailing. This demo uses the same-document API, and it skips transitions entirely when you prefer reduced motion.

The code

1. The whole basic API

document.startViewTransition(() => {
  // any DOM update: swap views, re-render a list, toggle a class
  showDetail(place);
});

2. Shared-element morph (photo and title fly into place)

// give both ends the SAME name; each name must be unique per snapshot
thumbImg.style.viewTransitionName = 'wander-img-amalfi';
titleEl.style.viewTransitionName = 'wander-title-amalfi';
// ...render the detail view with the same two names...
const t = document.startViewTransition(() => showDetail('amalfi'));
t.finished.finally(() => {
  thumbImg.style.viewTransitionName = '';
  titleEl.style.viewTransitionName = '';
});

3. Custom animation, pure CSS

::view-transition-old(wander) {
  animation: slide-out 380ms ease-in both;
}
::view-transition-new(wander) {
  animation: slide-in 380ms ease-out both;
}
@keyframes slide-out { to { transform: translateX(-72px); opacity: 0; } }
@keyframes slide-in { from { transform: translateX(72px); opacity: 0; } }

4. Feature-detect and respect reduced motion

const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;

function update(fn) {
  if (document.startViewTransition && !reduce) {
    document.startViewTransition(fn);
  } else {
    fn(); // plain instant swap: the free fallback
  }
}

Honest notes

  • The fallback is doing nothing. A browser without the API runs your update function directly and the user sees an instant cut. No polyfill needed; you are adding polish, not a dependency. Flip the toggle above to feel the no-transition version.
  • Names must be unique. Two visible elements sharing one view-transition-name in the same snapshot abort the transition. This demo generates one name per photo and per title (wander-img-amalfi, wander-title-amalfi, …).
  • Morphs and panel motion don't mix. On the slide and zoom presets the whole journal panel is the animated element, so the shared-element morph is skipped there. It only runs on Auto, where the panel itself just crossfades.
  • Same-document vs cross-document. This page demos same-document transitions. For classic multi-page sites, @view-transition { navigation: auto; } gives you crossfades between full page loads with zero JavaScript, where supported.
  • Reduced motion. View transitions are motion. If the user asked for less of it, skip the transition. This demo checks prefers-reduced-motion live and swaps instantly when it is set to reduce.
  • Real use, on my own site. The theme toggle on dominic.balass.one wraps its data-theme swap in document.startViewTransition(), so the whole page crossfades between themes instead of snapping. Four lines, feature-detected, skipped for reduced motion.
