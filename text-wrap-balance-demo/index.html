Every headline eventually breaks with one lonely word sitting on the last line. The old fixes were non-breaking spaces, hand-placed line breaks, and hoping nobody resized the window. One declaration balances the lines for you. Drag the slider below and watch the orphan appear and disappear.

The fallback is free

A browser that does not know text-wrap: balance ignores the declaration and wraps the headline the normal way. The page looks the same as it always did. Nothing breaks, nothing needs a polyfill. Add the line and every modern browser gets better headlines.

@supports (text-wrap: balance) {
  h1, h2, h3 {
    text-wrap: balance;
  }
}
Worth knowing: browsers limit balancing to short blocks for performance. Chromium balances up to 6 lines, Firefox up to 10. Past that the rule quietly stops applying.
Worth knowing: text-wrap: balance is for headings and short text. Its sibling text-wrap: pretty is for body copy and is a different feature with different support, so do not swap them.
