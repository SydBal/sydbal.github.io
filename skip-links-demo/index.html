Skip links save keyboard users eighteen Tabs

Every page on most sites opens with the same long navigation. A keyboard user presses Tab through all of it, on every page, before reaching the content they came for. One link at the top of the page fixes it. This page has one. Press Tab right now and you will meet it.

Feel the difference

Below is a small sample site with 18 navigation links, the same shape as the nav at the top of this page. Run it both ways and count the Tabs. Press the Start button, then press Tab until you reach the article. The counter only counts forward Tabs.

Mode: with a skip link
0 Tabs pressed
Press Start tabbing, then keep pressing Tab until you reach the article.
    <a href="#main-content" class="skip-link">
  Skip to main content
</a>

<main id="main-content" tabindex="-1">
  ...the article...
</main>

    The whole fix is two lines

    The link goes first in the page, before the navigation. It points at the main content, and the main content takes tabindex="-1" so the browser moves keyboard focus there, not just the scroll position. Hidden until focused, visible the moment a keyboard user presses Tab.

    .skip-link {
  position: absolute;
  top: -100px; left: 1rem;
}
.skip-link:focus {
  top: 1rem;
}
    WCAG 2.4.1 Bypass Blocks, Level A: "A mechanism is available to bypass blocks of content that are repeated on multiple Web pages." A skip link is the most direct way to provide it.

    Four ways teams get it wrong

    Hidden with display: none

    The link is invisible to sighted users and unfocusable for keyboard users. It may as well not exist. Hide it off screen instead, and reveal it on focus.

    Target without tabindex="-1"

    The page scrolls to the content but keyboard focus stays behind in the nav. The next Tab sends the user right back into the menu they just escaped.

    Not first in the page

    A skip link buried after the nav, the search box, or a cookie banner is no skip at all. It has to be the first focusable element on the page.

    Done right: one link, first, visible on focus

    First focusable element, clear text like "Skip to main content", visible when focused, target with tabindex="-1". That is the whole pattern.

    Try it on this page

    Reload, press Tab once, and the skip link for this page appears at the top left. Press Enter and focus jumps straight here, past all 18 links in the nav above. No JavaScript runs any of it. The link, the target, and two CSS rules are the entire implementation.
