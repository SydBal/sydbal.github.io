Alt text: what the screen reader actually hears

A screen reader cannot see your images. It reads the alt attribute out loud instead. Three words of lazy alt text can hide a chart's whole point, and one empty attribute can silence a decoration that should never have spoken.     The rules behind it

    • Describe the purpose, not the pixels. A chart's alt text should carry the trend, not the fact that it is a bar chart. Ask what the reader would miss if the image vanished.
    • Never start with "image of" or "photo of". The screen reader already announces that the element is an image. Those words are dead weight before the useful part starts.
    • If the image adds nothing, leave alt empty on purpose. alt="" is a deliberate instruction: skip this. It is not laziness, and it is not the same as leaving the attribute off.
    • Never leave the alt attribute off entirely. With no attribute at all, some screen readers fall back to reading the file name out loud, which is worse than silence.
    • A functional image gets the function, not the picture. An icon button's alt text is its name: "Search", not "magnifying glass". An image that is the only content of a link or button is never decorative.
    WCAG 1.1.1 Non-text Content, Level A: every image that carries information needs a text alternative that serves the same purpose, and decorative content must be implemented so assistive technology can ignore it. One short sentence is usually enough. There is no character limit in the standard.
