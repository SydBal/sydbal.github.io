Mix colors in the stylesheet

Mixing two colors in CSS used to mean precomputing hex values or reaching for a preprocessor. color-mix() blends them live, with a percentage, in any color space. Change the inputs below and the browser does the math.

The mixer

#7c3aed
#ffffff
result

color-mix(in oklch, #7c3aed 50%, #ffffff)

Switch the color space and watch the middle of the scale change. srgb midpoints often look muddy or grey. oklch keeps the hue and stays bright, which is why it is the usual pick for UI work.

One brand color, a whole palette

Pick a brand color and every variant below regenerates from it. No new hex values, no Sass function. This is the whole point.

Tint
color-mix(in oklch, var(--brand) 80%, white)
Hover
color-mix(in oklch, var(--brand), black 14%)
Subtle background
color-mix(in oklch, var(--brand) 12%, transparent)
Muted text
color-mix(in oklch, var(--brand) 55%, var(--ink))

The button above uses the same trick: its hover state is color-mix(in oklch, var(--brand), black 14%). Change the brand color and the hover follows.

The pattern

:root {
  --brand: #7c3aed;
}

.button {
  background: var(--brand);
}

.button:hover {
  background: color-mix(in oklch, var(--brand), black 14%);
}

.card {
  background: color-mix(in oklch, var(--brand) 12%, transparent);
}

Fallback for the long tail: write the static color first, then the color-mix() line. A browser that cannot parse the second declaration keeps the first.

.button:hover {
  background: #6a30d4;
  background: color-mix(in oklch, var(--brand), black 14%);
}
